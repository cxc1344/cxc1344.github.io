聊天机器人只会聊天，BotHive 不止

BotHive 是一套装在手机里的多 Bot 协作系统。你可以自带 API Key，自建 AI 员工，为每个 Bot 设定人格、模型和岗位；它们能群聊、私聊，也能组成一支真正分工的队伍。

总经理流水线负责立项、派活、审查与返工。每个 Bot 还有独立长期记忆和 Ubuntu 沙箱，能装包、跑命令、读写文件；锁屏后也能保持在线。

肚子里真有一台 Ubuntu

左边这个终端不是画出来的装饰——BotHive 里每个 Bot 都有自己的 Ubuntu 24.04 环境，通过 PRoot 跑在你的手机上。Bot 在里面装包、跑命令、读写文件，和真机一个用法。

  • Kotlin + Jetpack Compose
    原生开发，界面全应用采用液态玻璃——你现在看到的这块面板，就是网站的复刻。
  • PRoot · Ubuntu 24.04
    每个 Bot 独立沙箱，互不串门，重置即重生。
  • 仅 ARM64
    针对现代安卓手机原生构建。
