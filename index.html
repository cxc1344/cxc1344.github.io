多 Bot 共存

每个 Bot 独立人格设定、独立模型、独立长期记忆。养一群，各自记各自的事。

真沙箱

每个 Bot 有自己的 Ubuntu 环境：能装包、跑命令、读写文件。玩坏了，一键重置。

双模式

聊天 Bot 模式陪聊；Agent 模式自己干活——以截图感知屏幕、自己操作界面。

例行任务与工作流

定时让 Bot 自己干活；多步骤流程编排成工作流，到点自动跑。

远程 MCP 与技能包

接远程 MCP 服务器，装技能包。Bot 的能力边界，由你决定扩到哪。

命令批准卡

危险操作先弹卡确认，你点了才执行。锁屏也在线，后台保活。

bot@hive: ~/sandbox
bot@bothive:~$
需要批准：rm -rf ~ 此操作会清空沙箱主目录，Bot 无法自己撤销。

肚子里真有一台 Ubuntu

左边这个终端不是画出来的装饰——BotHive 里每个 Bot 都有自己的 Ubuntu 24.04 环境，通过 PRoot 跑在你的手机上。Bot 在里面装包、跑命令、读写文件，和真机一个用法。

  • Kotlin + Jetpack Compose
    原生开发，界面全应用采用液态玻璃——你现在看到的这块面板，就是网站的复刻。
  • PRoot · Ubuntu 24.04
    每个 Bot 独立沙箱，互不串门，重置即重生。
  • 仅 ARM64
    针对现代安卓手机原生构建。
